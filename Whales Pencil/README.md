# 神笔鲸良（Whale's Pencil）

一块**铺满整个桌面**的透明画布。agent 用任意颜色画，你从悬浮球取一支红铅笔也能画，**两边都能擦掉对方画的东西**——这样就能靠「指着说」来交流。

不是画在 DSH 窗口里：画布是桌面上的全屏窗口，DSH 也在它下面。

## 四个界面元素

| 元素 | 是什么 | 何时出现 |
|---|---|---|
| **悬浮球** | 一个 52×52 的红黑圆球，左键双击进画布，右键出菜单 | 常驻，可拖到任意位置 |
| **画布** | 全屏透明层，能画线、写字、擦除 | 双击球进入，`Esc` 退出 |
| **灵动岛** | 屏幕顶部中央的一条状态胶囊 | agent 干活时自动出现，干完消失 |
| **菜单** | 球菜单 2 项，画布菜单 4 项 | 右键触发 |

## 悬浮球

**左键双击** → 进入画布（球自动隐藏）
**左键单击** → 无动作（防误触）
**拖动** → 移动到任意位置，系统原生拖动，完全跟手
**右键** → 弹出菜单：`呼唤 agent` / `一键清除`

球可以拖到屏幕边缘，最多藏到只剩 16px 露在外面，不会被拖丢。

> 球是**独立窗口**，不是画在画布上。画布空闲时是鼠标穿透的，画在它上面的东西点不到。

## 画布操作

| 操作 | 效果 |
|---|---|
| **左键拖动** | 画红线 |
| **Shift + 左键** | 橡皮擦（擦掉光标下的笔画和文字） |
| **右键** | 弹出菜单（**不擦除**） |
| **滚轮** | 调粗细（1–30 px），光标旁显示宽度 |
| **Esc** | 退出画布，球回来 |

画布菜单（4 项）：

```
文本框
─────────
呼唤 agent
一键清除
─────────
退出作
```

**「文本框」会在你右键的位置**弹出输入框，而不是固定角落。

## 文字是可复制的容器

文字不是图案，是真正的文本容器。**用户文字和 agent 文字一视同仁**：

| 操作 | 效果 |
|---|---|
| 鼠标悬停 | 光标变 I 型 |
| 拖动 | **按字符逐个选中** |
| 双击 | 选一个词 |
| `Ctrl + A` | 全选 |
| **`Ctrl + C`** | **复制到系统剪贴板** |

文字框是只读的 `TextBox`，选中和复制都是 Windows 原生行为。

## 输入文字

右键 → 「文本框」→ 在点击处出现输入框：

- **回车** → 换行（真正支持多行）
- **点击框外** → 提交
- **Esc** → 取消

提交后变成红色文字标签，同时写进 `user.json` 给 agent 看。

## 灵动岛

屏幕**正上方中央**的半透明胶囊，显示 agent 在干什么：

| 状态 | 显示 | 圆点颜色 |
|---|---|---|
| 思考 | `思考中 5s` | 灰蓝 |
| 读取文件 | `读取 eye 3s` | 青色 |
| 调用工具 | `调用 pencil 12s` | 绿色 |
| 空闲 | **完全消失** | — |

**右侧有红色停止按钮** → 点击直接中断 agent 任务，岛立刻消失。

岛是**独立窗口**，可点击（画布本身是穿透的，点不到）。

## 呼唤 agent

右键球（或画布菜单）→「呼唤 agent」：

1. 窗口**抓一张全屏截图**，通过 attachment 服务投递给模型
2. 同时写 `summon.json`
3. Host 读到之后，把一条 prompt 投递进**最近用过画笔的那个会话**
4. agent 被唤醒并附带截图

投递结果写在 `summon-ack.json`，成功是 `{"ok":true}`，失败带 `error`——不静默。

## agent 作画

```
pencil { action: "draw",  items: [...] }        // 任意颜色
pencil { action: "erase", ids: ["a3-1"] }       // 精确点名
pencil { action: "erase", rects: [{...}] }      // 按区域
pencil { action: "scene" }                      // 看画板上有什么
pencil { action: "annotate", source: "图.png", items: [...] }
pencil { action: "overlay", overlay: "start" }
```

图元：`rect / ellipse / path / arrow / text / image / pixels`。坐标默认是**桌面物理像素**，`(0,0)` 是屏幕左上角；`unit: "window"` 是屏幕百分比。

**agent 不能一键清除**——清理整块画布等于推翻用户的工作，只有用户能做。agent 想移除自己的东西，用 `erase` 精确点名。

## 图片标注

```
pencil { action: "annotate", source: "原图.png", items: [{type:"arrow", ...}] }
→ 写出 Processed image/原图-pencil-20261019135723.png
```

原图不动，结果另存。所有产出**统一进 `Processed image` 文件夹**。

## 为什么这么设计

### 三个独立窗口

| 窗口 | 用途 | 点击 |
|---|---|---|
| 画布 | 绘图 | 仅绘制时可点，其余穿透 |
| 悬浮球 | 入口 | 始终可点 |
| 灵动岛 | 状态显示 | 始终可点（停止按钮） |

**必须分开**：画布空闲时 `WS_EX_TRANSPARENT`（鼠标穿透），画在它上面的按钮永远点不到。这是一个被踩过三次的坑。

### 文件通道

两个进程靠文件通信，一个文件只有一个写者：

| 文件 | 写者 | 读者 |
|---|---|---|
| `scene.json` | Host（agent） | 窗口 |
| `user.json` | 窗口（用户） | Host |
| `commands.json` | Host | 窗口 |
| `clear.txt` | 窗口 | Host |
| `stop.txt` | 窗口（停止按钮） | Host |
| `status.json` | Host | 窗口（灵动岛） |

**停止按钮为什么用文件而不是 HTTP**：DSH 的 web 服务只接受携带活跃会话的请求，画板窗口是独立进程没有会话，HTTP 会返回 401。

### 心跳

窗口每秒检查 `alive.txt`，超过 6 秒没更新就**自己关掉**——宿主崩了也不会在桌面上留一个永远置顶的透明窗。

## 五个必须记住的坑

**1. 必须用 `cmd /c start` 启动**

直接 `spawn('powershell.exe')` 拉起的 WPF 窗口和宿主共享窗口站，**秒退且无报错**。

**2. 高 DPI 缩放要换算**

WPF 用设备无关单位。125% 缩放下直接按物理像素画会放大 25%。

**3. `pencil.ps1` 必须纯 ASCII**

Windows PowerShell 5.1 读无 BOM 的 `.ps1` 会用 ANSI 代码页。中文文案走 `labels.json`。

**4. PowerShell 注释里不能有反引号**

`` ` `` 是转义符，写在注释里也会破坏解析，报错位置会指向很远的地方。

**5. 拖动无边框窗口不能用 `DragMove()`**

`DragMove()` 需要标题栏或可缩放边框，`WindowStyle = 'None'` 的窗口没有，会**静默失败**。改用 `ReleaseCapture()` + `SendMessage(WM_SYSCOMMAND, SC_MOVE)`。

## 结构

| 文件 | 作用 |
|---|---|
| `index.js` | Host：场景、`pencil` 工具、路由、窗口生命周期、灵动岛状态 |
| `client.js` | 浏览器：设置页 |
| `pencil.ps1` | 桌面窗口：画布 + 悬浮球 + 灵动岛 |
| `annotate.ps1` | 图片合成 |
| `locate.ps1` | 定位插件目录 |
| `skills/` | `pencil-board` 和 `pencil-summon` 两个技能文档 |

状态目录：`~/.dsh/whale-pencil/`

## 已知限制

- 只在 **Windows** 上能跑。
- 画布打开时会接住整个桌面的鼠标（要画就得这样）。
- 用户只有红色；要换色得由 agent 画。
- 多屏按虚拟屏幕铺满，但坐标原点在主屏左上角。
- 文本选中由画板手动驱动（因为画布持有鼠标），选区是按字符的，但不是完整的文本框（没有拖放、没有右键菜单）。
